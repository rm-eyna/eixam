# Eixam

Eixam és un joc de trets per a un jugador: defensa el far contra els eixams de criatures que baixen.

## Com jugar

Obre `index.html` al navegador. No cal instal·lar res.

## Controls

- Fletxes o A/D: moure's
- Espai: disparar i començar
- P: pausa

## Regles

- Els escuts es van desgastant amb els impactes.
- Tens 3 vides.
- Les oleades són cada cop més ràpides.
- El rècord es guarda al navegador.

Fet com a prova del centre de control d'rm amb Claude Code.
